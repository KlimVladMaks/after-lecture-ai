# ПослеЛекции — прототип мобильного приложения студента

Интерактивный макет мобильного приложения «ПослеЛекции»: экраны студента и базовые переходы между ними. Это **не рабочее приложение**, а прототип для проверки интерфейса: авторизация, проверка ИИ, push-уведомления и сохранение данных имитируются, все лекции и персональные данные вымышлены.

Прототип свёрстан только под мобильный экран. На компьютере его удобно смотреть в мобильном режиме инструментов разработчика.

## Технологии

- [Vite](https://vite.dev/) + React 19;
- Tailwind CSS 4;
- Lucide React (иконки);
- React Router (HashRouter) — переходы между экранами и работа кнопки «Назад».

Сервер и база данных не используются: всё состояние хранится в памяти браузера.

## Запуск

Требуется Node.js 20.19+ (рекомендуется актуальная LTS) и npm.

```bash
cd ui-prototype
npm install
npm run dev
```

Откройте адрес из терминала (обычно <http://localhost:5173>).

### Как включить мобильный режим

1. Откройте страницу в браузере.
2. Нажмите `F12` (или `Ctrl+Shift+I`) → вкладка **Device toolbar** (`Ctrl+Shift+M`).
3. Выберите, например, **iPhone 14 Pro** или задайте размер `390 × 844`.
4. Обновите страницу.

Макет занимает всю ширину экрана и ограничен 430 px, поэтому на компьютере выглядит как телефон по центру страницы.

## Быстрый сценарий

1. На экране входа нажмите **«Войти в демо-режиме»**.
2. На главной нажмите **«Ввести код»**.
3. Введите код **`4821`** и откройте опрос.
4. Ответьте на пять вопросов: один вариант, несколько вариантов и короткий текст. После каждого ответа ИИ показывает объяснение.
5. Нажмите **«К отзыву о лекции»**, поставьте оценку и отправьте отзыв.
6. Посмотрите итоговую справку, затем откройте историю и один из сохранённых диалогов.

## Демо-коды

| Код | Что произойдёт |
|---|---|
| `4821` | Успешный вход в опрос |
| `1111` | Ошибка «Код не найден» |
| `0000` | Ошибка «Опрос закрыт преподавателем» |
| `2222` | Ошибка «Срок прохождения истёк» |

## Демо-настройки

В разделе **«Профиль»** есть переключатели:

- **«Имитировать ошибку ИИ»** — следующий ответ сохранится, но проверка завершится ошибкой. В чате появится кнопка «Повторить проверку». Чтобы проверка прошла успешно, выключите переключатель и повторите.
- **«Показать пустую историю»** — на экране истории отображается пустое состояние.
- **«Сбросить демо-состояние»** — возвращает исходные данные прототипа.

Также в профиле находится выход из аккаунта.

## Экраны

| Маршрут | Экран |
|---|---|
| `/#/login` | Вход |
| `/#/register` | Регистрация (доступна роль студента) |
| `/#/reset` | Восстановление пароля |
| `/#/home` | Главная |
| `/#/join` | Ввод кода доступа |
| `/#/quiz` | Чат опроса с проверкой ИИ |
| `/#/feedback` | Отзыв о лекции |
| `/#/result` | Итоговая справка |
| `/#/history` | История пройденных опросов |

Любой экран можно открыть напрямую по ссылке — для этого в нём предусмотрены демонстрационные данные.

## Что именно имитируется

- **Вход и регистрация** — принимаются любые корректные email и пароль от 4 символов.
- **Проверка ответов** — тестовые вопросы сравниваются с правильными вариантами; короткий ответ оценивается по длине текста (демонстрационная эвристика, а не настоящая языковая модель).
- **Задержка ИИ** — около одной секунды, чтобы увидеть состояние «ИИ проверяет ответ…».
- **Дедлайн и закрытие опроса** — только через демо-коды ошибок.
- **История и результат** — хранятся в памяти до перезагрузки страницы; после неё возвращаются исходные демо-данные.
- **Push-уведомление** — обозначено текстом в блоке комментария преподавателя.

## Ограничения

- Реализован только сценарий студента. Экраны преподавателя появятся в следующих версиях прототипа.
- Нет реального сервера, REST API, авторизации, базы данных и интеграции с LLM.
- Нет автоматических тестов и полноценной дизайн-системы: это учебный макет.

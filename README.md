# Приложение «ПослеЛекции»

Приложение «ПослеЛекции» делает опрос после лекции коротким и полезным: студент проверяет себя и отмечается на лекции, преподаватель получает аналитику понимания материала, обратную связь о лекции и учёт посещаемости без ручного сбора. Ключевой принцип: опрос не влияет на оценки студентов.
